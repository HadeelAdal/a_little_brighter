# A Little Brighter

A starter e-commerce website for **A Little Brighter**, an art project where product sales can contribute to a mental-health fund.

## Included

- Home page
- Shop with category filtering
- Product pages
- Session-based shopping cart
- Mission page
- Impact/transparency page
- Contact page
- Responsive design
- Placeholder product images

## Run locally

1. Install Python 3.10+.
2. Open a terminal in this folder.
3. Create a virtual environment:

   python -m venv .venv

4. Activate it.

   Windows:
   .venv\Scripts\activate

   macOS/Linux:
   source .venv/bin/activate

5. Install dependencies:

   pip install -r requirements.txt

6. Run:

   python app.py

7. Open http://127.0.0.1:5000

## Before launch

- Replace the placeholder artwork/images with your own.
- Change the secret key in `app.py`.
- Add a real payment provider and checkout flow.
- Add shipping/tax logic appropriate to your business.
- Define the exact contribution model for the mental-health fund.
- Add legal pages and your actual contact details.
- Do not describe the project as a registered nonprofit/charity unless the relevant legal structure and registrations are actually in place.
- Replace the placeholder impact numbers with verified figures.
